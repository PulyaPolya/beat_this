# Beat This!
This is the repository made for beat tracking part of the master thesis called "Beat Tracking for Genre-Related Datasets Obtained by Clustering". 

This project is based on the work by Francesco Foscarin, Jan Schlüter and Gerhard Widmer called  "[Beat This! Accurate Beat Tracking Without DBN Postprocessing](https://arxiv.org/abs/2407.21658)".
